## Projetos

### Análise e Classificação da Relevância de Campeões no CBLOL

Projeto de análise de dados e Machine Learning aplicado ao cenário
competitivo de League of Legends.

**Principais variáveis utilizadas no modelo:**

| Variável | Descrição |
|---|---|
| `avg_elders` | Média de Dragões Anciões conquistados |
| `avg_firstdragon` | Média de primeiros dragões conquistados |
| `avg_firsttower` | Média de primeiras torres destruídas |

- Dados de partidas competitivas de 2025 e 2026
- Análise exploratória
- Classificação binária
- Random Forest

🔗 [Ver projeto](https://github.com/fuu-jpg/lol-relevancia-campeoes)
